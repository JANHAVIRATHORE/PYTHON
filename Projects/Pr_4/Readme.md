## ✨ Features

🔹 Input and store numerical data in a 1-D array

🔹 View stored dataset

🔹 Remove duplicate values

🔹 Display dataset summary using built-in functions

🔹 Calculate factorial using recursion

🔹 Filter data above or below a threshold

🔹 Sort data in ascending or descending order

🔹 Display complete dataset statistics

🔹 Function documentation using Docstrings

---

### 📌 Function Types Demonstrated

| Function Name  | Type                                        |
| -------------- | ------------------------------------------- |
| `create()`     | Without Parameters & Without Return Value   |
| `built_in()`   | Without Parameters & Without Return Value   |
| `fact(no)`     | With Parameters & With Return Value         |
| `above(value)` | With Parameters & Without Return Value      |
| `below(value)` | With Parameters & Without Return Value      |
| `ascen()`      | Without Parameters & With Return Value      |
| `decen()`      | Without Parameters & With Return Value      |
| `statis()`     | Without Parameters & Multiple Return Values |

### 💻 Python Concepts Used

* Functions
* Recursion
* Lists
* List Comprehension
* Built-in Functions (`len()`, `min()`, `max()`, `sum()`)
* Sorting
* Multiple Return Values
* Menu-Driven Programming
* Docstrings
* Data Filtering

### 🚫 Concepts Not Used

The following concepts were intentionally not used because they were not required for the project objectives:

* `global` keyword
* `*args`
* `**kwargs`

This project focuses on demonstrating function types, recursion, list operations, sorting, filtering, and basic data analysis techniques.
