# ✨ About The Project

The **Student Data Organizer** is a simple console-based Python application designed to manage student records easily and efficiently.

This project helps users perform basic **CRUD operations**:

* ➕ Add Student
* 📖 View Student Records
* ✏️ Update Student Information
* ❌ Delete Student
* 📚 Display Subjects Offered

---

# 🔥 Special Features

✅ Menu-Driven Program
✅ Records Stored Using Dictionaries & Lists
✅ Subjects Managed Using Sets
✅ Student Records Sorted by ID
✅ Beginner-Friendly Python Project

⚠️ **Important Rule:**

> 🆔 Student **ID** and 📚 **Subjects** cannot be changed once entered.
