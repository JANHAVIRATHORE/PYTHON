# 📖 About the Project

The **Multi-Utility Toolkit** is a Python package-based application that combines multiple everyday utilities into a single menu-driven program. It demonstrates the practical use of **Python packages, modules, object-oriented programming, file handling, exception handling, and built-in libraries**.

This project is designed as an educational toolkit that showcases how different Python concepts can be integrated into one application.

# 🧩 Modules Overview

### 🏠 Moduler_packager.py

Acts as the main entry point of the project. It displays the menu and imports the required module based on the user's choice.

### 📅 Date_Time.py

Performs date and time operations such as displaying the current date, calculating date/time differences, formatting dates, and countdown timer.

### ➗ Mathematical_ope.py

Provides mathematical utilities including factorial, compound interest, trigonometric calculations, and area of geometric shapes.

### 🎲 Random.py

Generates random numbers, random list values, secure passwords, and OTPs using Python's `random` module.

### 📁 File_Operator.py

Implements a Personal Journal Manager where users can add, view, search, and delete journal entries stored in a text file.

### 🔍 Explore_module.py

Uses Python's `dir()` function to display the available attributes and methods of any module.

### 📦 **init**.py

Marks the **Mypackage** directory as a Python package.

# ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in your IDE.
3. Run the main file:

```bash
python Moduler_packager.py
```

4. Select an option from the menu to explore different utilities.
