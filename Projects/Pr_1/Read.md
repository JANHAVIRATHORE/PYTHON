# 🌟 Interactive Personal Data Collector

Welcome to the **Interactive Personal Data Collector** project!  
This is a beginner-friendly Python program that collects personal information from the user and displays it with additional details like:

✅ Data Types  
✅ Memory Addresses  
✅ Approximate Birth Year Calculation  

Perfect for learning:
- Python Input/Output
- Variables
- Data Types
- Type Conversion
- `type()` Function
- `id()` Function
- Basic Arithmetic Operations

---

# 🚀 Features

✨ Collects user details interactively  
✨ Displays variable data types  
✨ Shows memory addresses using `id()`  
✨ Calculates approximate birth year  
✨ Beginner-friendly and easy to understand
