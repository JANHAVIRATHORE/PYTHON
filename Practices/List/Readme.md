# 📋 Python List Management System

A simple and interactive **Menu Driven Python Program** to perform various operations on Lists using Python.
This project is beginner-friendly and helps in understanding **Lists, Loops, Match-Case, and CRUD Operations** in Python.

---

## 🚀 Features

✨ Create a List
👀 View List Elements
✏️ Update Existing Values
🗑️ Delete Elements
📈 Sort List in Ascending Order
🔄 Reverse List Order
❌ Exit Program

---

## 🛠️ Technologies Used

* 🐍 Python 3
* Lists
* Loops
* Match-Case Statement
* Conditional Statements

---

## 📌 Program Menu

```text
1. To Create a List
2. To View the List
3. To Update the List
4. To Delete the List
5. To Sort the List Order
6. To Reverse the List Order
7. To Exit
```
