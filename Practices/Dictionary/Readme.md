# 📌 About The Project

This is a **menu-driven Student Management System** created using **Python Dictionary** concepts.
The project allows users to perform basic CRUD operations:

✨ Add Student Details
👀 View Student Details
✏️ Update Student Details
🗑️ Delete Student Details

It is a beginner-friendly project to practice:

* Python Dictionaries
* Loops
* Conditional Statements
* User Input Handling
* CRUD Operations
