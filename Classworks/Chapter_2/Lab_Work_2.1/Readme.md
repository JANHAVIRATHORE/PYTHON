# 📌 About This Project

This repository contains simple Python programs based on:

✅ `if` Statement
✅ `if-else` Statement
✅ `if-elif-else` Ladder
✅ Nested Conditions

These programs are designed for beginners to practice decision-making concepts in Python.

---

# 📂 Programs Included

## 1️⃣ Even or Odd Number Checker

Checks whether a number entered by the user is even or odd.

### 💡 Concepts Used

* Modulus Operator `%`
* `if-else` Statement

---

## 2️⃣ Age Category Checker

Categorizes users into:

* Child 👶
* Teenager 🧑
* Adult 👨
* Senior 👴

### 💡 Concepts Used

* Conditional Ladder
* Logical Operators

---

## 3️⃣ Largest Number Finder

Finds the largest among three numbers entered by the user.

### 💡 Concepts Used

* Comparison Operators
* `if-elif-else`

---

## 4️⃣ Positive, Negative & Neutral Number Checker

Checks whether a number is:

* Positive ➕
* Negative ➖
* Neutral 0️⃣

### 💡 Concepts Used

* Ladder `if` Statement
